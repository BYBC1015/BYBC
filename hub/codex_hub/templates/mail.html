接入说明

向下面的地址发送 JSON 请求。访问密钥放在请求头；收件人、主题和正文由脚本决定。

POST {{ endpoint }}
Authorization: Bearer <你的发信访问密钥>
Idempotency-Key: server-alert-20261004-001
Content-Type: application/json

{
  "to": ["recipient@example.com"],
  "subject": "服务器提醒",
  "text": "检测到需要处理的情况。"
}

收件人：to 可为一个地址或 1–20 个地址的列表；每个地址单独投递。

正文：text 和 html 至少提供一项，合计不超过 128 KiB。可用 reply_to 指定回复地址。当前不支持附件、自定义发件人、抄送或密送字段。

避免重复：一个事件对应一个固定的 Idempotency-Key（8–128 字符）。重试时保留此值和内容；新事件使用新值。

返回与查询：首次受理返回 202 和记录 id；重复请求返回原记录和 200。以同一密钥请求 GET {{ endpoint }}/{id} 可查看每个收件人的状态；请求列表地址可查看最近 50 条。

失败处理：401 检查密钥，409 检查重复编号或地址暂停，422 检查内容；429 达到额度，503 服务暂不可用。网络中断后使用原编号重试，勿另建编号重复发信。
