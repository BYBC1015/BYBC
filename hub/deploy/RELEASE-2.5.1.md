# Hub 2.5.1 — 分工与工作归属

六个智能体原先只通过自然语言区分职责，多人选择会复制整份要求，换请求编号也可能重复派工。本版加入显式角色、单项交付登记和受约束的总控分派。

- 同一项目每个分工角色只有一位负责人，按任务类型自动选择；救火队员仅补专业职责空缺。
- 多选工作交总控拆分；重复派工复用已有任务，角色冲突和修改冒充新工作会被拒绝。
- 总控始终检查当前执行凭据，普通任务接口不能跳过专业派工检查。
- 连续修改沿最新接续任务串行处理，避免引用原任务时另开并行分支。
- 身份页可查看和修改自动分工角色，总控上下文包含职责边界和近期工作登记。

数据库迁移仅新增字段、索引和工作登记表，保留旧任务、经验与用户数据。新规则在设置总控分工角色的项目中启用，自定义旧项目保持兼容。

验证：完整回归 1117 项通过、1 项跳过；公开备份中的分工与工作接口回归 39 项通过。线上六个身份配置及九个页面核验通过；在服务器临时数据库副本上验证了自动选人、重复复用、冲突拒绝和通用支援，没有向正式工作队列加入测试任务。完整回归保留原有 Windows 符号链接跳过项及旧测试的编码/依赖弃用警告。

详见 [分工约定与限制](AGENT-ROLES.md)。角色匹配不代表所有外部工具均已具备执行条件。
