# Hub 2.8.0 · 桌面工作区与实时进度

日期：2026-10-29。配套 Windows Bridge / HubDesktop 1.1.0。

聊天页面通过事件通知及时获取新消息、任务变化和公开执行进度；连接中断时自动回到轮询，恢复后继续同步。正在输入的草稿和正在阅读的消息保持原位，任务结束后正式结果替换临时进度。登录过期明确提示重新登录，不再把认证失败误报成等待网络。

CLI 执行期间持续读取输出，展示真实公开回复和工具阶段。该通道使用 CLI JSONL 事件，不保证所有模型逐字输出。内部推理、原始工具参数和交付协议不进入公开进度；进度发送失败不会阻塞执行，也不作为任务成功依据。

进度受设备、执行代次、任务版本和租约约束，序号递增且幂等。取消、完成、超时或重新安排之后，旧执行不能覆盖新任务。正式交付与清除草稿在同一事务内；回滚保留原状态。事件连接会持续检查登录和项目有效性，并限制并发连接数量。

桌面端复用网页工作区，工程文件仍在执行设备本地处理。原连接控制台收进系统托盘，关闭前台窗口不停止后台。三种执行方式保持不变：普通咨询、一次性处理和本地工程对话。模型分配沿用总控策略及用户覆盖，避免额外重复的模型决策。

更新前备份代码、数据库和已安装程序。保留既有七个智能体、历史、附件、设备与独立工具配置。Windows 版需要 WebView2 Runtime；网页仍可独立使用。
