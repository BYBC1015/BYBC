## 总控额度不足时的处理

默认保留原对话、消息、附件和同一项任务。新执行器能区分首次请求被服务明确拒绝与工作中途断线。前者按设备和模型服务退避，最初等待十分钟，连续拒绝时最长等待一小时。恢复后同一服务先尝试一项工作，避免大量积压消息同时占用额度。其他执行者可继续领取各自的工作。

在工作区设置的「模型服务 → 身份的模型分配」里选中总控，可以指定已接入本机的工具模型或外部 API 作为备用。变更服务地址或模型后需重新选择对应版本。带图片的任务需要备用服务支持图片，本地工程继续由拥有该工程的执行环境处理。任务已有输出、派工或工具操作时，保留执行收据供核对。额度相关测试使用隔离服务模拟拒绝响应。

配套 Windows 执行器为 1.3.1。早期版本的历史失败没有开工前拒绝证明，升级时保留原记录。Android 0.3.0 继续使用原生资料页，额度等待状态通过 Hub 接口更新。
