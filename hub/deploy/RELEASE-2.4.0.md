# Codex Hub 2.4.0

2026-10-27 · 网页端体验与执行可靠性更新

本版围绕真实智能体协作完善网页端：智能体保留长期身份、职责与经验，可参与不同工作对话；对话、智能体与执行连接分别管理。

## 主要更新

- **工作区体验**：三栏工作区、圆形身份入口、明确收件人、可折叠任务与成果详情；补齐离线排队提示、友好时间、键盘操作和窄屏布局。查看身份不会改变派单对象。
- **图片与文件**：聊天支持多选、拖放、粘贴图片、预览和移除附件，也可只发送文件。上传显示进度，失败保留当前页面的选择；附件随任务交给执行者，消息中可查看图片或下载文件。
- **逐任务模型选择**：依据执行连接上报的模型目录，由总控按任务选择模型与思考档位，并记录选择来源。用户可手动指定；已开始的任务保留原模型。设置页仅提供已上报的有效档位，校验失败可原页纠正。
- **反馈与每周维护**：工作区和项目相关页可提交问题或建议，自动附带工作与页面上下文。每周按项目汇总为工程师维护任务，避免重复排队；工程师记录验证证据后可关闭问题，报告人可重新打开。单条反馈不会立即触发模型执行。
- **租约与发送回执**：任务执行使用租约与执行代次校验，阻止过期执行者回写。发送结果不确定时查询原请求回执，保留原编号重试，减少重复派单；登录续期后可保留附件继续发送。

## 网页部署验证

2.4.0 网页服务已部署。健康检查、工作区、对话、身份、任务、反馈和维护等 9 个页面均返回正常响应；未变化工作区的条件请求返回 304。
工作区首页与对话页在 1440、1280、1024 三种宽度下没有横向溢出或浏览器脚本错误。
每周维护定时检查已启用；连续两次检查复用了同一项维护任务。首轮任务已由总控独立选择模型并在实际执行设备上启动，排队与启动不等于维护完成。

## 当前边界

- PRO 执行机尚未实机接入，相关跨机器接力仍待实机验证。
- 执行连接离线时可排队；进行中的任务不会因连接中断而盲目切换机器或重复启动，需先确认执行状态。
- 尚未上传成功的附件内容仅保留在当前页面内存中；刷新后若需重试上传，可能需要重新选择原文件。
- 本轮以网页端为主。手机完整适配、独立 iOS App 与 Windows EXE 客户端属于后续工作，本版不包含这些客户端交付。
