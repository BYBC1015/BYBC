# Hub 2.7.0：按工作选择执行方式

普通咨询由总控在聊天中回应和安排；单张图片、参考检索和一次文件处理直接交适合的专业身份；持续工程默认在本地项目工作会话接续。身份、模型、会话和设备仍分别管理。

- 新增锦衣卫，负责项目参考研究。优先最近 365 天优秀案例，核实来源及案例实际日期，注明旧例、未知日期与适用范围。
- 三种执行路线独立于工作目录隔离。工程与后期默认项目会话；其他专业交付默认单次执行。总控可根据任务显式选择，并记录原因。
- 聊天保留可靠执行记录及完整消息，不挤占待办和历史工作列表。
- 项目接续、交接答复和重复提交保持原路线。项目会话不能使用每项任务都会变化的临时目录。
- 工作卡显示“本地工程 / 单次执行 / 聊天协调”，不要求用户理解运行参数。

需要配套本机 Bridge 1.0.33 才能续接本地项目会话。旧任务保留原本单次执行语义，不自动迁移历史对话。发布前备份数据库与变更文件，先在生产数据库副本验证迁移和交接，再更新服务。

验证覆盖角色分工、去重、聊天与成果展示、附件、在线状态、路线冻结、修改接续、执行收据与锁。具体记录见本次发布的本地回归及部署报告。
