# Hub 2.6.2：在线状态自动更新

此前网页自动刷新仅更新消息及详情区域，左侧头像和输入框仍显示打开页面时的旧连接状态。本版将各处连接状态纳入现有约两秒一次的页面同步，不增加模型调用。

- 头像状态点、状态文字、身份详情、团队面板和输入框提示同步更新。保留焦点、勾选、草稿及未发送附件。
- 专用执行器仍每 45 秒发送独立心跳；超过 120 秒未收到心跳则显示离线。旧版连接维持原有宽限时间。网页登录在线不等于执行器在线。
- 浏览器暂时无法连接 Hub 时显示“状态待确认”；网络恢复或切回页面后重新同步。在线状态不触发任务转移或重复执行。
- 提供专用执行器的 Windows 隐藏启动脚本，沿用原配置、执行收据与单实例保护，可接入用户登录启动入口。

回归覆盖在线、心跳过期、重连、前台断网、状态变化后的页面缓存，以及桌面与窄屏下的焦点、输入、附件和人员选择保留。

本版为网页与启动辅助脚本更新，不新增安装包。源码备份不含用户配置、密钥、数据库或工作附件。
