# Bridge 1.0.33：持续本地工程工作会话

持续工程使用 Codex CLI 的显式线程编号续接，在配置的真实工程目录执行，并沿用本机已启用的 MCP 配置。聊天和单次制作维持独立执行；用户手动模型设置与总控本次模型分配继续有效。

会话绑定按设备、项目、Hub 对话和执行身份区分，保存在稳定的 `project-sessions` 目录，不能放进每项任务临时目录。首次执行从真实 `thread.started` 事件记录编号，后续使用该编号 `exec resume`；不猜测最近对话，不使用 `--last`，不接管正在运行的桌面用户对话。

目录变化、线程编号不匹配或上轮结果不明会保留记录并明确报错，不悄悄新建重做。跨进程锁避免同一会话并发写入；已完成收据可重用。任务结果仍走原有执行代次校验和成果预览上传流程。

已通过真实 CLI 两轮上下文续接探针；再次读取实际线程元数据确认工作目录、模型及权限保持一致。独立模块测试覆盖锁、收据、错误、身份隔离；执行器集成测试覆盖模型、图片、本机配置继承及重复执行保护。

这提供由 Bridge 管理的本地持续工作会话，不代表自动接入任意已经打开的 Codex 桌面对话，也不代表已经实现跨设备搬迁完整 CLI 历史。设备更换需要对应工程文件与上下文交接。
