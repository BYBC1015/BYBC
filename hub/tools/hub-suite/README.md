# Codex Bridge 1.0.30

本版更新“达芬奇调色 · 节点预设”1.0.1：修复满额配方导入导出、配置损坏启动、旧确认残留和异常恢复，增加跨进程写入互斥及逐阶段目标校验。保留基础八节点及六种风格、独立调色版本、强度调整和设备检测。面向已还原的 Rec.709 SDR；人物／衣物泛绿由独立局部节点按镜头处理，不自动抠像。详见工具目录 PRESETS.md 和 MIGRATION.md。

本版加入节拍工坊的逐轨曲线编辑：管弦乐、钢琴、吉他等可用曲线调整曲调、节奏疏密与音符长短，曲调吸附音阶，段落长度支持 1–16 小节。保留 1.0.27 对新版 Codex 模型菜单和自动发送的兼容修复。

Windows 10/11 64 位统一安装包。Bridge 是主入口，安装后默认随 Windows 登录自动启动并连接；桌面和开始菜单入口均为 **Codex Bridge**。可在主页面取消“开机自启”。新设备需先配置本设备的 Hub Token。

安装器启动后自动检测旧软件，也可点击“检测旧软件”重新检查，或“添加旧程序位置”检查其他目录。检测范围包括当前用户的软件注册、桌面与开始菜单入口、自启和运行中的 Bridge、常见安装位置、下载目录中的可灵版本文件夹，以及目标目录旁的旧安装暂存。不会遍历全盘。

默认勾选“继承已有 Token 和配置”和“新版验证成功后清理旧程序”。已有有效 Bridge 配置逐字保留，可灵继续读取原 Windows 用户的加密凭据。若缺少有效 Bridge 配置，会从已识别旧版的配置继承 Hub 地址、Token、AI 绑定和项目设置。多个不同配置需通过“选择旧配置”明确来源；不会自动拼接不同设备的账号。Token 不显示在检测列表、不写入升级记录、不打进安装包。配置损坏或迁移失败时停止升级并保留旧版。

安装后逐文件校验通过，才按已发布版本的文件指纹清理旧程序。配置、作品、历史、被修改和不认识的文件始终保留；旧可灵任务快捷方式会指向新版并保留批次参数。正在运行的 Bridge 需先从托盘退出；其他正在使用的旧工具会暂时保留，关闭后重新运行安装器即可再次检测。达芬奇运行环境不清理。

升级记录保存在 `%APPDATA%/CodexBridge/upgrade-report.json`。默认清理完成后只保留新版程序；可取消清理以保留旧程序。安装目录里的额外个人文件也会保留在原路径。此功能只管理已识别程序，不删除下载压缩包或开发源代码。

主页面保留 AI 绑定、网络与系统、运行日志，点击 **打开工具箱** 按需打开以下独立窗口：

- 视频末帧延长 1.0.1：成片在素材目录下的 `BYBC_延长一秒`。
- 可灵批处理 1.1.1：输出位置在工具内选择；首次使用需配置 API 凭据。
- 音乐制作 · 节拍工坊 0.5.0：鼓机、128 个音色、曲线主旋律／伴奏和自然环境声；音频直接保存到系统下载目录，保留现有方案和历史。
- 达芬奇调色 · 节点预设 1.0.1：基础八节点、银幕中性、丝绢柔光、古风琥珀、冷峻悬疑、暖光冷影、银盐黑白。当前单片段应用；保留原版本与操作日志。

节拍工坊的程序、音色和环境声已随包安装，仍需电脑安装 **DaVinci Resolve Studio 21.1**，使用其 Electron 和 Python 运行环境。安装包不包含达芬奇，也不会修改其已有插件。可以在达芬奇未打开时编辑、试听和导出；向时间线交付时需打开达芬奇，并将外部脚本设置为“本地”。原始声库许可证和环境声署名要求随工具保留。

其他工具无需另外安装 Python 或 FFmpeg；使用 Windows 自带的通用 C 运行库。工具箱关闭后 Bridge 继续运行，工具不会随开机启动，也不会因打开窗口自动提交生成。

默认安装在 `%LOCALAPPDATA%\Programs\CodexHub`，可选择其他目录。程序与附属工具安装在一起。移动安装目录后，请重新运行安装器修复入口和自启路径。

安装包不包含设备 Token、API 密钥、客户素材或个人方案。Bridge、可灵和节拍工坊继续使用原用户配置目录。更新期间先暂存 `.previous-…` 旧目录，成功后按所选清理选项处理；失败时保留旧版。卸载保留用户配置、历史和导出文件，只移除属于当前安装的自启入口。

调色程序也需要 Resolve Studio 21.1 的完整运行环境，换电脑会重新检测安装位置，不依赖原设备盘符。用户配方和历史在 `%APPDATA%/HubColorWorkshop`，LUT 应用时安装在本机 Resolve LUT 目录；升级不覆盖已有 LUT。Windows x64 已实测，macOS／Linux 未适配。

构建：在 `codex-hub` 目录运行 `uv run --with pyinstaller --with pystray --with psutil python tools/hub-suite/build.py --kling-dir <可灵1.1.1目录>`。音乐组件使用 `music-files.json`，调色组件使用 `color-files.json` 固定源码和资源校验清单，不读取个人数据。产物在 `dist/suite`。加 `--reuse-payload` 可复用经校验的视频工具，但始终重建 Bridge 和安装器。
