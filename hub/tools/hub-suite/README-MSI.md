# BYBC Hub 1.3.1 · Windows 标准安装版

本次维护更新保留统一设置、绑定执行电脑的模型服务和默认 Codex CLI 执行方式，并补充额度耗尽的执行收据。只有完整协议能证明本次调用在任何模型输出或工具调用之前被服务方明确拒绝时，服务器才可按已配置策略安排备用或等待；中途失败、网络中断、结果不明不会自动重跑。该恢复需要支持此协议的 Hub 服务端。旧后台继续运行时不会自动取得新版执行能力。

安装面向 Windows 10 1803（内部版本 17134）及以上，或 Windows 11 x64，仅用于当前 Windows 用户。默认位置为 `%LOCALAPPDATA%\Programs\CodexHub-MSI\1.3.1`。此目录与旧版 custom 安装并存；安装不会接管、清理或覆盖旧版 custom 安装目录，不迁移旧版 custom 快捷方式或自启，不强制关闭正在运行的旧程序。旧标准 MSI 版本按 Windows Installer 的升级事务处理。

安装完成后，从开始菜单的 **BYBC Hub 1.3.1** 打开。这个入口运行本版 `CodexBridge.exe`，安装器不会自动启动它。如果旧版 Bridge 后台仍在运行，新入口只打开同目录的新前台，继续使用既有后台，不另起重复工作进程。需要切换到新版后台时，请先从旧版托盘正常退出，待任务安全结束后再打开新入口。安装本身不要求强制结束旧后台。

如果已经打开同一 Hub 的旧窗口，窗口去重可能继续显示旧前台。关闭旧 Hub 窗口后，再点击新开始菜单入口即可使用新前台；关闭前台窗口不会强制停止后台任务。

安装前会只读检查系统目录中的 Visual C++ v14 x64 运行库，包括 VC/MFC 的版本、架构和本版所需接口。缺失或不满足时，安装器会停止并给出[微软官方运行库页面](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)和[微软 x64 下载入口](https://aka.ms/vc14/vc_redist.x64.exe)。Hub 不自动修改系统运行库、安全设置或网络设置。桌面工作区另需 Microsoft Edge WebView2 Runtime；节拍工坊和达芬奇调色仍需 DaVinci Resolve Studio 21.1 的相应环境。

程序文件由 Windows Installer 安装、修复和卸载。安装器等待系统事务结束后，核对产品登记、安装标记和全部清单内程序文件，才报告文件已安装完成。用户取消会单独显示取消。Windows 返回需要重启时，会明确提示“待重启生效”，不会自动重启，也不会把尚待重启的文件称为已经全部就绪。安装日志会显示保存位置，保留内容有长度上限。

用于标准修复和回退的原始安装源，经过完整校验后保存在 `%LOCALAPPDATA%\BYBC\CodexHubInstallerCache\<产品编号>\<安装包编号>.msi`，不依赖下载目录、临时解包目录或原外层 EXE。请保留此缓存；标准卸载也会保留它，避免在回退完成前删除所需安装源。它只包含本产品公开安装文件，不包含 Token 或个人配置；本版不会自动清理其他安装源缓存。

已有 `%APPDATA%` 配置、Token、历史任务、作品与个人文件不归 MSI 管理，安装和卸载均不会写入这些内容。节拍工坊的 `tools/beat-workshop/runtime.json` 是本机偏好，不随 MSI 安装；只有用户明确打开音乐工具时，应用才按已有行为创建或更新它。它也不属于 MSI 的修复或卸载清单。

卸载请使用 Windows“设置 → 应用”中的本版 **BYBC Hub** 条目。标准卸载仅移除本 MSI 拥有的程序文件和本版入口，保留用户添加的文件、本机偏好和用户配置；因此安装目录在卸载后可能仍存在。不要使用旧版 custom 卸载程序来清理此目录。

本包不包含设备 Token、API 密钥、客户素材或个人方案。Windows 完整安装、修复、卸载及应用启动的实测结果以本次发布记录为准；先决检查通过不代表所有 Windows 10/11 版本均经过实机验证。
